## Estrategia de Migración (SIN DROP DE BD)

**Método seguro:** `prisma db push`

Por qué:
- La base de datos es **desarrollo local** (`valery_db` en localhost:5432)
- `db push` aplica ALTER TABLE `ADD COLUMN` — **no borra datos ni tablas**
- No requiere archivos de migración (adecuado para etapa temprana de desarrollo)
- Los campos son `String?` (opcionales) — no rompen registros existentes

Comandos:
```bash
# 1. Modificar schema.prisma
# 2. npx prisma generate  (regenerar cliente)
# 3. npx prisma db push   (agregar columnas a BD existente)
# 4. Reiniciar backend
```
